# LAD для Tekla Structures 2025

LAD — приложение WPF для работы с выбранными объектами чертежа Tekla Structures.

## Сборка и запуск

1. На Windows установите Tekla Structures 2025, Visual Studio с поддержкой .NET Framework и пакет разработчика .NET Framework 4.8.
2. Откройте `LAD.sln` и восстановите NuGet пакеты (`Tekla.Structures.*` версии `2025.0.0`).
3. Соберите решение и запустите LAD при открытых модели и чертеже Tekla. Выберите объекты чертежа перед запуском.

Сборка и запуск в Tekla требуют проверки на Windows. В облачной среде Linux проверяются только структура проекта, синтаксис исходников и наличие библиотек NuGet.

## Папка макросов

LAD получает список каталогов из настройки Tekla `XS_MACRO_DIRECTORY` и использует первую доступную для записи папку `drawings`. Путь установки Tekla в коде не задан.

Если у пользователя нестандартная конфигурация, можно задать переменную среды `LAD_MACRO_DIRECTORY` с полным путём к папке `drawings`. Эта папка также должна входить в пути поиска макросов Tekla. Для каждого запуска LAD создаёт отдельный макрос с префиксом `LAD_`. Старые макросы и созданные Tekla файлы сборки удаляются при следующем запуске LAD, когда им больше суток.

При смешанном выделении LAD открывает одно окно для первого распознанного типа объекта. Для болтов он изменяет все выделенные болты и сохраняет чертёж один раз.

Готовая 64-битная сборка доступна в архиве `LAD-Tekla-2025.zip` в артефактах GitHub Actions и ветке `build-output`. Распакуйте архив и запустите `LAD.exe` при открытом чертеже Tekla 2025.

## Автообновление LAD

После первой установки направьте кнопку или шорткат Tekla на `LADLauncher.exe` в папке LAD. При каждом запуске он проверяет `version.txt` ветки `build-output` этого репозитория, сравнивает SHA256 и, если нужно, заменяет только `LAD.exe`. Библиотеки Tekla и сам лаунчер остаются на месте. Если GitHub недоступен, запускается уже установленная версия. Ошибки обновления записываются в `%LOCALAPPDATA%\LAD\launcher.log`.

Для автоматического скачивания без учётных данных репозиторий LAD должен быть `Public`. Если он `Private`, лаунчер запускает локальную копию, но не сможет обновить её. Публикация репозитория открывает весь исходный код и историю коммитов.
